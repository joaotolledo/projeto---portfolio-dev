# 💻 Meu Portfólio Pessoal

Este repositório contém o código-fonte do meu portfólio pessoal de desenvolvedor. O objetivo deste projeto é centralizar minha trajetória profissional, demonstrar minhas habilidades técnicas e exibir os projetos que venho desenvolvendo.

🔗 **Confira o site online:** [Visualizar Portfólio](https://joaotolledo.github.io/projeto---portfolio-dev/)

---

## 🚀 Funcionalidades

- **Seção "Sobre Mim":** Uma breve introdução sobre minha carreira e objetivos.
- **Lista de Projetos:** Galeria com os principais trabalhos e links para repositórios.
- **Habilidades Técnicas:** Exibição das tecnologias que domino (HTML, CSS, JS, etc).
- **Formulário de Contato:** Links integrados para redes sociais e e-mail.

## 🛠️ Tecnologias Utilizadas

Para a construção deste projeto, foram utilizadas as seguintes tecnologias:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, animações e layouts (Flexbox/Grid).
- **Google Fonts:** Tipografia personalizada para uma melhor experiência visual.
